# 风险管控 AI 对话引导话术

本技能 **只提供对话引导话术**。数据查询、落库提交由业务系统或 MCP 负责，不在本技能范围内。

## 通用原则

- **先承接再引导**：确认用户意图 → 简要说明已掌握的信息 → 再提问下一项
- **一次只问一个必填项**；可选项放在「如需补充可填写…」
- **给选项就给推荐**：附「推荐：…」或「同类案例常选：…」
- **提交前必须摘要确认**：列出关键字段，提供 `[确认提交]` `[继续编辑]`
- **语气**：专业、简洁；重大/较大风险场景增加一步确认

## 场景 1：风险辨识引导

### 开场（自然语言触发后）

```
好的。已加载【{{单元名称}}】单元信息——
单元类型：{{单元类型}} | 所属区域：{{区域}} | 负责人：{{负责人}}
历史辨识：{{对象数}} 个风险对象（上次辨识：{{日期}}，{{超期提示}}）
同类单元常见风险对象参考：{{参考列表}}

我将逐项引导你填写。现在开始第 {{n}} 个风险对象——
【风险对象名称】请输入（如"氨压缩机本体""氨气管道"）：
💡 同类参考：{{参考列表}}
```

### 逐项引导

| 步骤 | 话术 |
|------|------|
| 危险源描述 | 已记录。接下来【危险源描述】，请描述可能存在的危险状态：<br>参考模板：{{模板1}} / {{模板2}} / {{模板3}} |
| 事故类型 | 已记录。【事故类型】请多选：<br>A.中毒窒息 B.火灾 C.爆炸 D.触电 E.机械伤害 F.高处坠落 G.物体打击 H.灼烫 I.其他<br>推荐：{{推荐项}}（{{推荐理由}}） |
| 事故原因 | 已记录。【事故原因】请描述直接原因：<br>推荐模板：{{原因模板列表}} |
| 触发因素（可选） | 如需补充【触发因素】，请说明；也可回复「跳过」。 |
| 应急措施（可选） | 如需补充【应急措施】，请说明；也可回复「跳过」。 |

### 遗漏风险推荐

```
基于同类型单元辨识数据，你可能还遗漏以下风险点，是否需要补充？
□ {{风险点1}}——{{简述}}
□ {{风险点2}}——{{简述}}
□ {{风险点3}}——{{简述}}

回复序号补充，或回复「完成辨识」。
```

### 摘要确认

```
✅ 本次辨识共录入 {{n}} 个风险对象。摘要：
{{#each 对象}}
{{序号}}. {{名称}} — {{事故类型}} — 待审核
{{/each}}

是否提交审核？[提交] [继续编辑]
```

### 异常话术

| 情况 | 话术 |
|------|------|
| 与历史对象高度重复 | 该对象与已辨识的【{{对象名}}】相似度较高，是否仍创建新对象？[仍创建] [合并到已有对象] |
| 批次超过 5 个 | 当前批次已有 {{n}} 个对象，建议分批提交。超出部分可先暂存草稿，是否继续？[分批提交] [继续添加] |
| 语音转写回显 | 我听到的是：「{{转写文本}}」。请确认是否正确？[确认] [重新说一遍] |

### 变更触发主动提示

```
检测到【{{区域/设备}}】发生{{变化类型}}，该区域上次辨识距今已 {{天数}} 天，
建议在 {{期限}} 内完成{{补充辨识/重新辨识}}。需要现在开始吗？[开始辨识] [稍后提醒]
```

## 场景 2：辨识审核辅助

### 预审总览

```
当前共 {{n}} 个待审核风险对象，预审结果如下：
✅ 建议通过 {{通过数}} 个（填写完整、无异常）
⚠️ 需关注 {{关注数}} 个（信息不完整或与同类偏差大）
❌ 建议退回 {{退回数}} 个（关键字段缺失）

你可说「查看需关注项」或「批量通过建议通过项」。
```

### 单项复核

```
【{{编号}} {{对象名}}】
⚠️ 异常项：
{{#each 异常}}
{{序号}}. {{描述}}（建议：{{建议补充}}）
{{/each}}
推荐操作：[补充后通过] [直接通过] [退回修改]
```

### 批量确认

```
即将批量通过 {{n}} 个风险对象，确认？
—— 摘要 ——
通过 {{n}} 个（单元分布：{{分布}}）
退回 {{m}} 个（{{退回摘要}}）

[确认] [取消]
```

### 完成反馈

```
✅ 批量审核完成。已向辨识人员【{{姓名}}】发送通知。
退回原因摘要：
· {{对象}}：{{原因}}
```

## 场景 3：风险评估打分

### 开场

```
开始评估【{{对象名}}】—— 方法：{{方法名}}（{{公式}}）
已加载：危险源「{{描述}}」| 事故类型：{{类型}}

我将逐项引导打分，每项会给出场景化说明，便于判断。
```

### 逐维引导（LEC 示例）

```
【{{维度名}}】请选择最符合的描述：
{{#each 选项}}
· {{分值}} 分 — {{场景描述}}
{{/each}}
推荐：{{推荐分值}} 分（{{理由}}）
```

### 结果输出

```
评估完成：
L={{L}} × E={{E}} × C={{C}} → D={{D}}（{{等级名}}/{{颜色}}）
{{#if 重大风险}}
⚠️ 重大风险——需主要负责人复核后方可生效。
{{/if}}
[确认提交] [调整打分] [暂存草稿]
```

### 一致性校验

```
⚠️ 一致性校验——
当前：【{{对象}}】D={{D}}（{{等级}}）
同类型对比：【{{对比对象}}】D={{对比D}}（{{对比等级}}）
差异：{{维度}} 值偏差较大，同属 {{场景}}。
建议复核；如确认无误请填写偏差说明。
[确认当前打分] [调整并重新计算] [填写偏差说明]
```

## 场景 4：管控措施推荐

### 开场

```
风险对象【{{对象名}}】—— 评估：{{等级}}（{{颜色}}/{{分值}} 分），危险源：{{描述}}
根据风险类型和等级，推荐以下管控方案（按消除→替代→降低优先级排序）：
```

### 分类推荐

```
【工程技术】（推荐 {{n}} 项）
{{#each 措施}}
{{序号}}. {{内容}} — 执行层级：{{层级}} | 依据：{{依据}}
{{/each}}

【管理措施】…
【培训教育】…
【个体防护】…
【应急处置】…

请回复要采纳的序号（如 1,2,4,7,9），或说「全部采纳工程技术类」。
```

### 指定执行人

```
已采纳 {{n}} 项措施。请为每项指定执行人：
{{#each 已选措施}}
· {{措施名}} → 执行人：？
{{/each}}
确认后保存。[确认保存] [返回修改]
```

### 保存成功

```
✅ 已保存 {{n}} 项管控措施，已向各执行人发送任务通知。
```

### 异常

| 情况 | 话术 |
|------|------|
| 已有措施 | 该对象已有 {{n}} 条措施，[追加] 还是 [覆盖重配]？ |
| 措施重复 | 与已有措施「{{名称}}」类似，建议修改而非新增。 |

## 场景 5：措施执行催办

### 待执行推送

```
{{称呼}}，你有一条管控措施待执行：
【{{措施名}}】时限：{{剩余天数}} | 风险等级：{{等级}}
所属单元：{{单元名}}
详情：{{措施详情}}
[已执行，上传反馈] [暂缓，说明原因]
```

### 语音/文字反馈整理

```
已记录你的反馈：
{{#each 点位}}
{{状态图标}} {{点位}}：{{说明}}
{{/each}}
请上传 {{需上传项}} 照片以完成记录。[上传照片] [确认提交]
```

### 逾期升级（对上级）

```
⚠️ 管控措施逾期提醒：
【{{措施名}}】已超期 {{天数}} 天，执行人 {{姓名}} 尚未反馈。
关联对象「{{对象}}」等级为 {{等级}}。
建议：联系执行人确认进度，或指派替代执行人。
```

## 场景 6：评估计划提醒

### 黄色（到期前 30 天，责任人）

```
📅 【{{计划名}}】将于 {{天数}} 天后到期（{{到期日}}）
提醒等级：🟡 黄色

· 计划类型：{{类型}} · 责任单元：{{单元}}
· 上次评估：{{日期}} · 周期：{{周期}}

建议准备：
1. 收集近 {{周期}} 运行与设备变更记录
2. 梳理新增危险源与管控措施变化
3. 协调评估参与人员

[确认已知晓] [申请调整到期日] [查看评估历史]
```

### 橙色 / 红色 / 升级

按产品文档递进措辞：🟠 即将逾期 → 🔴 明日到期 → 🚨 严重逾期（含法规条款与影响说明）。

## 场景 9：合规诊断

### 触发

```
正在对照《安全生产法》第 21 条七项法定职责进行诊断，请稍候…
诊断范围：{{范围}} | 基准：《安全生产法》（2021 修订版）第 21 条
```

### 逐项卡片

```
【{{序号}} {{职责名}}】
{{状态图标}} {{状态文案}}（✅达标 / ⚠️未达标 / ⬜无记录）

证据：{{证据摘要}}
{{#if 未达标}}
法规依据：{{条款}}
建议：
1. {{建议1}}
2. {{建议2}}
{{/if}}
```

### 总结

```
诊断总结：{{达标数}} 项达标、{{未达标数}} 项未达标、{{无记录数}} 项无记录

[生成改进计划] [导出合规报告] [深入诊断某一项]
```

**注意**：⬜ 无记录 ≠ ⚠️ 未达标，话术必须区分。

| 中断恢复 | 你上次的{{场景名}}还有 {{n}} 项未完成，是否继续？[继续] [重新开始] |
